③七类资产

1 · 图形符号必做

A 推荐
B 斜光文字线
C 译字升级

A「琥珀闪电」：一道闪电 = 速度承诺 + 荧光笔笔触。推导链：品类普查（全是「A/文」双字符与气泡）→ 空档（速度母题无人用）→ 人格（快）→ 参数：笔画占比 ≈ 20%（效率工具 12–16% 上沿，「快」需要力量感）、右倾 8°（能量）、单母题（2 秒徒手可画、剪影可认）。

独占性测试：放到 DeepL / Google 翻译旁边——蓝底文字符号 vs 琥珀闪电，一眼可分 ✓。16px 托盘尺寸仍可读（见上方尺寸条）。

全触点锁死：托盘图标、选中态、开关、焦点环、收藏星、截图选区框、进度光带、错误条文案重音——全部同一族色值。

3 · 形状语言推荐

不确定进度条 = 一道斜切流光（替换胶囊往复）
强调分隔 / 选中态下划

母题：「一道斜切的光」（14° 斜切渐隐光带）。只在强调处出现：进度条、翻译完成光痕、空状态装饰。卡片/按钮的连续圆角体系（6/8/10/12/14）保持不变——形状签名不稀释克制。

独占性测试：竞品进度条全是横向胶囊，斜切流光是品类内未见的手势。

4 · 动效签名「译光闪落」必做

自动检测⇄中文（简体）📌 ✕
予人玫瑰，手有余香。
Bing · 142ms

触发时机 = 本品唯一的情绪峰值：译文落定。一道琥珀光痕沿译文区划过（420ms，cubic-bezier(0.2,0,0,1) 减速收尾），随后译文以 160ms 淡入。每次成功翻译都出现——重复建立条件反射；失败/降级不播（错误时刻不给奖赏）。

独占性测试：品类常规是「转圈等待」；「结果落定 + 光痕」是把等待焦虑翻转为收获瞬间。reduced-motion 降级为直接显示译文。

5 · 启动仪式「首呼点亮」必做

速译已就位
Alt+D 呼出小窗
Alt+S 划词 · Alt+O 截图

托盘应用没有启动屏——仪式落在托盘气泡：启动完成后气泡浮现「速译已就位」，同时气泡内小窗缩略图标闪过一道琥珀流光（≤900ms，可忽略可跳过）。寓意：译路已点亮，随呼随到。首次呼出小窗时边框同款流光扫一圈（复用签名光，仅首次，不重复打扰）。

仪式三查：只复用琥珀光痕资产 ✓；一句寓意 ✓；≤3s、点任意处即消失 ✓；reduced-motion 直接显示静态气泡。

6 · 语言人格「干脆的动词句」必做

完成：「已复制译文」「已加入生词本」
降级：「Google 连不上，已用 Bing 重试」
出错：「Key 无效——到「引擎」页检查后重试」
空状态：「输入文字，按 Enter 翻译」
加载：「翻译中…」

三条铁律：动词开头说结果，不说过程；永远给出路，不甩错误码；不卖萌不道歉刷屏。句式统一「已 / 在 + 动词 + 宾语」。

闭眼测试：满屏「已…」句式 + 数字耗时（142ms），是速译说的话，不是通用系统腔。

7 · 声音与触感可选 · 本轮不做

托盘工具静音是礼貌——
不加提示音，光痕即签名。

评估：提示音在高频呼出场景是打扰（一天几十次），收益为负。留空位：若未来做「翻译完成」可选音，复用「一滴」轻声，默认关闭。

④触点分布

情绪峰值（签名动效驻场）

  • 译文落定 → 「译光闪落」光痕

  • 截图识别完成 → 钉图浮现 + 光痕

高频时刻

  • 加载 → 斜切流光进度带
  • 选中/开关/焦点 → 琥珀独占色
  • 收藏星 → 琥珀实心
  • 微文案 → 动词句人格

入口时刻

  • 托盘图标 → 琥珀闪电
  • 启动气泡 → 「速译已就位」仪式
  • 截图选区框 → 琥珀描边
