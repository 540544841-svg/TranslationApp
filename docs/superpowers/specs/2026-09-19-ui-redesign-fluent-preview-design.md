# 速译 UI v3.0「 Fluent 澈光」浏览器预览稿 — 设计文档

| 项目 | TranslationApp（速译） |
|---|---|
| 日期 | 2026-09-19 |
| 状态 | 待用户审阅 |
| 交付物 | `design-preview/` 纯静态 HTML 交互原型（浏览器预览，不动 WPF） |
| 关系 | 全新风格，替代 v2.0「琥珀流光」（v2.0 仅存档于 git 历史与 docs/） |

## 1. 背景与目标

用户决定放弃 v2.0 琥珀品牌体系，按 **Windows 11 原生 Fluent 观感**全面重设 UI（视觉 + 布局，功能集合不变），先在浏览器里以高保真可交互原型评审，方向确认后再另立任务落地 WPF。

**本轮范围内**：预览稿全部页面与交互演示。
**本轮范围外**：WPF 代码/主题改动、真实翻译调用、图标资产重绘（用占位图形，落地时再做）。

## 2. 设计原则（Fluent 体系）

1. **融入系统**：仿 Mica 材质（桌面壁纸色的低饱和渐变 + 细噪点）、原生窗口 chrome、Segoe 字族。
2. **轻量呼吸**：4pt 间距体系、发丝线分隔、卡片浮层代替密集边框。
3. **动效即反馈**：所有状态变化有 ≤200ms 的 controller 缓动（`cubic-bezier(0.1, 0.9, 0.2, 1)`），无品牌签名动效；悬停/按下/焦点环遵循 Fluent 交互层（Reveal 高光弱化版）。
4. **可达性**：正文对比 ≥ AA 4.5:1；焦点可见（2px accent 描边 + 1px 外隔）；动效尊重 `prefers-reduced-motion`。
5. **功能对等**：对照现有 WPF 界面逐元素清点，不新增/删减能力；文案沿用语言人格（动词开头、给出路）。

## 3. 品牌替换要点

| v2.0 琥珀流光 | v3.0 Fluent 澈光 |
|---|---|
| 独占色：琥珀 | 强调色：**青瓷蓝绿（Celadon Teal）**，介于蓝绿之间、避开翻译品类蓝色带与旧琥珀 |
| 图标：琥珀闪电 | 占位：单色「译」字标 + 圆角方块底（预览稿内示意） |
| 动效签名：译光闪落 | 取消。峰值时刻改为译文区 **fade-up 160ms** 入场 |
| 斜切 14° 形状语言 | 取消斜切；纯 Fluent 圆角体系 |

强调色三角色规则保留（填充 / 文字级 / 填充上文字），令牌名换成 Fluent 语义。

## 4. 设计令牌

### 4.1 色彩（Light / Dark 两套，键名一致）

| 令牌 | Light | Dark | 用途 |
|---|---|---|---|
| `--accent` | `#0F6E5D` | `#5CE0C7` | 交互填充：主按钮、开关选中、焦点环、导航选中条 |
| `--accent-text` | `#0B5A4C` | `#7DEBD6` | 文字/图标级强调 |
| `--on-accent` | `#FFFFFF` | `#0A2E27` | 强调填充上的文字 |
| `--accent-container` | `#DFF2ED` | `#17403A` | 色调按钮底、导航选中底 |
| `--window` | Mica 渐变 `#F4F5F3 → #E9EDEB`（加 2% 噪点） | `#202124 → #1A1B1E` | 窗口底（仿 Mica） |
| `--card` | `#FFFFFF`（72% 不透明 + `--card-stroke`） | `#2B2C2F` | 内容卡片 |
| `--card-stroke` | `#E1E4E2` | `#393A3D` | 卡片发丝描边 |
| `--text-primary` | `#1B1C1E` | `#F4F5F6` | 正文 |
| `--text-secondary` | `#5C6066` | `#A5A9AE` | 说明文字 |
| `--divider` | `#E7E9E7` | `#35363A` | 发丝线 |
| `--danger` / `--danger-bg` | `#C42B1C` / `#FDF3F2` | `#FF99A4` / `#3D1817` | 错误 |
| `--warning` / `--warning-bg` | `#8A5A00` / `#FFF8E7` | `#FCDCB5` / `#3B2E14` | 警告（纯系统语义，非品牌） |
| `--success` | `#217A45` | `#6CD691` | 成功徽标 |
| `--capture-scrim` | 两主题一致 `rgba(15,18,16,0.55)` | 截图遮罩不跟主题 |
| `--capture-selection` | 两主题一致 `#5CE0C7` | 选区框/手柄用强调色 |

浅深切换：`<html data-theme="light|dark">` + `localStorage` 记忆 + 默认跟随 `prefers-color-scheme`；切换按钮固定在每页右上角。

### 4.2 字体 / 字阶

- 字体栈：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif`；图标用内嵌 SVG（不依赖 Segoe Fluent Icons 字体，保证跨机一致）。
- 字阶：Caption 12 / Body 14 / BodyStrong 14/600 / Subtitle 20/SemiBold / Title 28（沿用 Fluent type ramp；WPF 落地时按比例折算回 11–19 档）。

### 4.3 间距 / 圆角 / 阴影

- 间距 4pt：4 / 8 / 12 / 16 / 24 / 32。
- 圆角：控件 4px、卡片 8px、浮层/小窗 8px、胶囊按钮 999px。
- 阴影：`Level 2`（卡片 0 1px 4px 8%/1px 描边）、`Level 8`（浮层/小窗 0 8px 24px rgba(0,0,0,0.24)）。

## 5. 页面清单与布局重设计

目录 `design-preview/`，共 5 页 + 共享样式脚本：

```
design-preview/
  index.html      总览 + 设计系统展示
  quick.html      翻译小窗
  settings.html   设置主窗口（7 个分区）
  pin.html        钉图窗口
  capture.html    截图选区 + 托盘菜单
  assets/tokens.css  base.css  icons.js  preview.js
```

纯静态零依赖，双击 `index.html` 即可浏览；页面间用相对链接互跳。

### 5.1 index（总览页）

- 顶部：品牌占位标 +「速译 v3.0 · Fluent 澈光」+ 主题切换。
- 五张页面入口卡（含各自 1:1 缩略预览框）。
- 设计系统区：色板矩阵、字阶样例、按钮全状态矩阵（default/hover/pressed/focus/disabled × 主要/次要/色调/文本/图标）、开关/下拉/输入框/徽标/键帽样例。
- 与 v2.0 差异说明表（§3）。

### 5.2 quick.html（翻译小窗，420×~360，呼出在模拟桌面背景上）

新布局（自上而下）：
1. **自绘标题条 32px**：左「译」标；中央**语言条**——`自动 ▾ ⇄ 中文 ▾`（胶囊式，中间互换按钮，点击互换有 120ms 旋转动画）；右 复制/收藏☆/关闭 图标按钮。
2. **输入区** 多行框，占位「输入文字，按 Enter 翻译」。
3. **发丝线**。
4. **译文区**：空态（淡字提示）/ 结果态（fade-up 入场）/ 引擎徽标行（当前引擎小徽标 + 「对比」「朗读」「钉图」文本按钮）。
5. **状态栏 28px**：加载中 = Fluent 环形指示 + 「Bing 翻译中…」；降级提示「Google 连不上，已用 Bing 重试」（中性灰，遵循失败才用红色的纪律）；错误态红字 + 重试按钮。

交互演示：内置 6 条词库模拟翻译；Enter 触发 600ms 假延迟出结果；复制弹 toast「已复制译文」；☆ 点亮；「对比」出双引擎分栏（两列卡片）；失败态可按钮切换演示。

### 5.3 settings.html（设置主窗，960×640）

新布局 = Fluent **NavigationView**：
- 左侧导航 260px：顶部搜索框（示意）、7 项导航（通用 / 热键 / 翻译 / 引擎 / 历史 / 生词本 / 高级），选中 = accent-container 底 + 左侧 3×16 圆角指示条（Fluent 标准样式，非斜切）。
- 右侧内容区：Subtitle 页头 + 分组卡片（SettingsCard：图标 + 标题 + 说明 + 右侧控件；SettingsExpander 可展开子项），滚动条为 Fluent 细条。

各分区内容对照现有 WPF 页面清点（现状为准）：
- **通用**：主题（跟随系统/浅色/深色 segmented）、开机自启、托盘气泡、小窗默认尺寸/位置记忆。
- **热键**：划词翻译 / 输入翻译 / 截图翻译 三个键帽录制框（点击→录制态→按键回填，含冲突提示演示）。
- **翻译**：当前引擎下拉、备用引擎顺序列表（可拖拽示意）、对比引擎多选、源/目标语言、TTS 开关与划词自动朗读。
- **引擎**：7 个引擎卡片（Bing/Google 免密钥徽标；腾讯/百度/Azure/DeepL/AI 密钥密码框 + 显示切换 + 测试连接按钮 + 配置徽标 + 可达性警告条），AI 卡含模型/温度/base-url 展开项。
- **历史**：搜索框 + 记录列表（原文/译文/引擎徽标/时间/收藏/删除）+ 空状态；导出 CSV/Anki 按钮。
- **生词本**：词条列表 + 删除 + 导出，空状态。
- **高级**：代理开关/地址/端口/认证、代理作用范围、OCR 语言、Paddle 模型常驻、钉图缩放步长、遮罩不透明度、重置设置。

交互演示：导航切换（hash 路由，可直链）、开关/分段/下拉即时响应、密钥显示/隐藏、测试连接按钮 loading→成功徽标。

### 5.4 pin.html（钉图窗，模拟钉在桌面一角）

- 图片区：用一张 CSS 绘制的"界面截图"样例，原文/译文浮层可切换（空格提示）。
- 底部悬浮**胶囊工具条**（acrylic 半透明 + blur）：缩放 −/+、不透明度滑杆、原/译切换、复制、朗读、收藏、关闭；悬停整条浮现、静止 2s 降到 60% 透明（演示用按钮可冻结）。

### 5.5 capture.html（截图选区 + 托盘）

- 背景：模拟桌面（渐变壁纸 + 两个假窗口卡片，其一带可 OCR 的英文段落）。
- 交互演示：按下即出现全屏遮罩 → 拖拽框选（accent 描边 + 8 向手柄 + 尺寸提示）→ 松手出选区工具条（识别翻译 / 复制图 / 取消）→ 点「翻译」收起遮罩并在选区旁落出 quick 小窗（联动演示）。
- 托盘：右下角任务栏条 + 点击弹出 acrylic 菜单：显示速译小窗 / 截图翻译 / 划词翻译 / 打开设置 / 退出（各项右侧以键帽示意各自热键，取值与用户设置一致）；「速译已就位」气泡示意。

## 6. 错误与边界处理（预览稿层面）

- 词库 MISS 时按「未命中 → 显示占位译文并标记示例数据」处理，不白屏。
- `localStorage` 不可用（file:// 部分浏览器）时主题切换退化为仅当前页生效，不报错。
- 所有页面在 125%/150% 浏览器缩放下不出现横向滚动。

## 7. 验证方式

1. 实现后逐页在浏览器打开自检：浅 + 深两主题、每页关键交互走查一遍。
2. 用 browser-use 对 5 页 × 2 主题截图留档到 `design-preview/screenshots/`（此目录加入 .gitignore，提交前确认）。
3. 对照 §5 各分区内容清单逐项核对无遗漏。
4. 本预览稿为设计产物，不进入 .NET 构建，不影响 975 项单元测试。
