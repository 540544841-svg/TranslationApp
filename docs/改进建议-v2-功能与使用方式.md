## A. 功能改进建议（增量）

### A1. 电商场景包（对作者本人价值最高，通用用户可忽略）

| # | 建议 | 说明 | 成本 |
|---|---|---|---|
| A1-1 | **俄语质量专项** | 品类差评通病是俄语机翻味重：为 zh↔ru/ru↔zh 默认走 AI 引擎 + 内置「电商俄语提示词」（敬称 Вы、尺码/材质术语、避免德式语序）；Bing/Google 俄语仅作降级 | 低 |
| A1-2 | **预置术语包** | 术语表（FR-031）支持按行业打包导入/导出：服装尺码（S/M/L→рус.）、面料材质、电子产品认证词（EAC/ГОСТ）、Ozon 类目高频词。用户可自建包、可分享 | 低-中 |
| A1-3 | **Listing 工作台**（批 2 候选） | 小窗加「长文模式」：整段产品描述翻 → 按「标题 / 要点 / 详情」三段结构化输出，逐段可换引擎重翻；本质是 TextChunker + 分栏 UI 的组合复用 | 中 |
| A1-4 | **字符计数与平台限制** | 输出时显示目标文本字符数，超 Ozon 字段限制（标题 200 等）标黄——纯本地计数 | 低 |

### A2. 翻译质量链路（通用）

| # | 建议 | 说明 | 成本 |
|---|---|---|---|
| A2-1 | **词典释义层** | 划词是单词时，结果区先给「词头 + 音标 + 简明释义」再给译文（v1 #11 mdx 导入的轻量前置版，不导库也能用：AI 引擎单次调用返回结构化 JSON） | 中 |
| A2-2 | **TM 回填可视化**（v1 #7 细化） | 命中历史相似句时显示「来自 3 天前的记录」并可一键改用机器重译，避免旧译文错误被固化 | 中 |
| A2-3 | **术语表反向保护** | 后置替换会把不该换的换掉（Target 撞上日常词）：替换前检查 Target 是否已存在于原文，命中冲突时词条标灰并提示 | 低 |
| A2-4 | **引擎看板加延迟列**（FR-034 增强） | 除成败外记 P50 响应耗时（只记耗时不记内容，不破隐私），帮用户选"能直连里最快的" | 低 |

## B. 使用方式改进建议（本轮重点）

### B1. 触发方式：从"背三个热键"到"多入口零学习"

现状：Alt+D / Alt+S / Alt+O 三个记忆负担 + 托盘菜单。品类标杆的演进方向都是**降低触发成本**：

| # | 建议 | 依据/参考 | 成本 |
|---|---|---|---|
| B1-1 | **双击修饰键触发**（默认候选） | 有道 Ctrl+Ctrl、PixPin Alt+Alt 已成肌肉记忆习惯；速译可支持「双击 Alt = 划词翻译」，键盘不离位。用低级键盘钩子实现，需处理误触阈值（250ms）与隐私模式豁免 | 中 |
| B1-2 | **鼠标侧键映射** | X1/X2 后键常被闲置；设置里做成可选映射（侧键=划词，前推=截图）。对卖家批量看俄语页面尤其顺手 | 低 |
| B1-3 | **悬停取词**（=v1 #5，批 2 已排期） | 沉浸式翻译 2025-04「不打断阅读」验证过的路径：选中→光标旁浮图标→点击出结果。与 B1-1/B1-2 并列成"四种触发任选" | 低-中 |
| B1-4 | **粘贴即译** | 小窗内 Ctrl+V 直接对剪贴板内容走完整链路（清洗→翻译），省一步"复制→关窗→划词" | 低 |

### B2. 结果呈现：从"一段译文"到"分层信息"

| # | 建议 | 说明 |
|---|---|---|
| B2-1 | **段落对齐视图** | 长文本（≥3 段）时默认「原文/译文逐段对照」而非整块译文；小窗内单列滚动，钉图沿用 BlockOverlay。参考沉浸式对照的留存口碑 |
| B2-2 | **一键换说法** | 结果行加「更口语 / 更正式 / 更简短」三个轻按钮（仅 AI 引擎时显示，内部就是三条预置 prompt 重请求）——把「润色」这个 DeepL Write 的核心价值做成 3 次点击内 |
| B2-3 | **复制策略显式化** | 复制按钮长按菜单：只复制译文 / 只复制原文 / 原文+译文。卖家贴 listing 时"只要译文别带引号"是高频痛点 |
| B2-4 | **朗读升级为影子跟读**（远期） | 逐句高亮 + 句间停顿，服务语言学习用户；对核心场景可选关闭 |

### B3. 会话与场景：从"每次现调"到"场景一档"

| # | 建议 | 说明 |
|---|---|---|
| B3-1 | **场景档案（Profile）** | 把「引擎 + 目标语言 + 清洗开关 + 术语包 + 隐私模式」打包成可切换档案：`阅读`（Bing+清洗开+术语开）/ `写作`（AI+更正式+俄语）/ `隐私`（本地优先+不入历史）。热键或托盘一键切——这是"每天几十次几秒即走"定位下**杠杆最大的交互改动** |
| B3-2 | **语言对记忆按应用** | 对浏览器默认 zh→en、对微信默认 en→zh 这类"按前台程序记语言对"（设置可关）。沙拉查词用户长期抱怨点 |
| B3-3 | **首次运行 30 秒上手卡** | 托盘气泡已有；补一张一次性小窗：三个热键键帽图 + "现在就试：选中这段字按 Alt+S"（选中即真译）。Pot 用户口碑里"开箱即用"权重很高 |

### B4. 回顾闭环：从"存了不看"到"顺手复习"

| # | 建议 | 说明 |
|---|---|---|
| B4-1 | **生词本每日 5 词**（可选开） | 每天首次呼出小窗时状态行给一个复习词，点☆跳过/记住；接 Anki 直推（v1 #3）前先用最轻方式验证需求 |
| B4-2 | **历史按"页面/项目"分组** | 同会话（30 分钟窗口）翻译自动归组，历史页按组折叠——找"昨天调那个 listing 的十来个词"比逐条翻快 |

### B5. 风险与红线（使用方式层面）

- 双击修饰键/全局鼠标钩子与游戏、远程桌面的兼容性：必须一键全关 + 隐私模式默认不启用钩子。
- 悬停图标、场景切换等一切新入口**不得增加译文落定延迟**（"快到无感"是唯一体验承诺，任何 >50ms 的入口预处理都要走异步）。
- 复制策略、粘贴即译涉及剪贴板：沿用现有"备份-还原-自写抑制"纪律，不新增常驻监听。
