# 速译功能升级建议（竞品调研 v1.0）

| 项目 | TranslationApp（速译） |
|---|---|
| 日期 | 2026-09-19 |
| 性质 | 调研建议文档，非承诺性规划；采纳与否逐项决策 |
| 调研范围 | 桌面划词（有道/欧路/Pot/CopyTranslator/GoldenDict-ng/TTime）、浏览器沉浸式（沉浸式翻译/沙拉查词/KISS/Trancy）、截图 OCR（PixPin/Umi-OCR/ShareX）、AI/CAT（DeepL/Trados/memoQ/彩云/讯飞）、字幕（BibiGPT） |

## 1. 现有功能盘点（截至阶段 5 + FR-030）

**取词与翻译**：热键划词（Alt+S，剪贴板备份-模拟复制-轮询-还原）、输入小窗（Alt+D，物理像素定位 + PerMonitorV2 DPI）、截图 OCR 翻译（Alt+O，Windows OCR + PaddleOCR 双引擎，模型内置零下载）、多引擎（Bing/Google 免密钥 + 腾讯/百度/Azure/DeepL/AI 端点）、引擎失败自动降级（FR-028）、多引擎对比（FR-020）、语言自动检测与置顶、3000 字符上限。

**结果呈现**：钉图窗原位替换（InPlace/BlockOverlay/SidePanel 三模式、原/译切换、缩放/透明度、5 张上限三重内存闸）、TTS 朗读（系统语音离线）、译文行操作（复制/收藏/朗读）。

**数据与学习**：历史 SQLite 5000 条（搜索/删除/清空）、生词本（导出 CSV/Anki TSV）、剪贴板监听自动翻译（防抖+限流，默认关）。

**系统与安全**：托盘常驻 + 气泡、单实例、开机自启、代理（作用范围可选 + DPAPI 加密）、深浅双主题 + 设计令牌体系、单文件自包含发布（<200MB 门禁）。

> 结论：热键即译链路的完成度已是第一梯队（Pot 都未做到原位替换钉图 + 双 OCR 引擎）。缺口集中在**翻译质量增强（术语/上下文）**、**学习闭环**、**批量/文档场景**三块。

## 2. 品类格局要点（2025–2026）

- **Pot 已归档**（最后版 3.0.7，2025-05）：开源划词第一梯队塌位，其用户外溢；插件式引擎脚本生态是它最受好评的设计。
- **沉浸式翻译信任滑坡**：2025-08 云端快照泄露用户保单/合同 + 以"安全"为由封禁自定义 API。反面教材，速译"本地优先、密钥自填"恰好是它的对位卖点。
- **沙拉查词一夜打挂**：Chrome MV2 清退（2026-09 完成）证明浏览器扩展形态脆弱；桌面原生热键工具是差异化站位。
- **DeepL 持续拉开质量差距**：术语表（glossary）、翻译记忆、Write 润色、`Ctrl+C+C` 原地替换。
- **CAT 工具（Trados/memoQ）验证了**：术语强制一致 + TM 复用 + 上下文预翻译对专业用户的留存价值极高。
- **PixPin/Umi-OCR 验证了**：批量 OCR、本地 HTTP API 是开发者/重度用户的高频刚需。

## 3. 建议清单

### P0 低成本高价值（建议下阶段做）

| # | 功能 | 借鉴 | 说明 | 成本 |
|---|---|---|---|---|
| 1 | **术语表 / 自定义指令** | DeepL glossary、CAT 术语强制 | 全局 + 按引擎注入：「把 X 译成 Y」映射表；AI 引擎拼进 prompt，官方引擎用其术语接口（DeepL v2 支持）；命中时译文区显示"应用了 2 条术语"徽标 | 低 |
| 2 | **隐私模式开关** | 用户对沉浸泄露的恐慌 | 开启后不入历史、不上传密钥外的内容；托盘图标变化提示状态。与"本地优先"品牌纪律同构 | 低 |
| 3 | **Anki 直推** | 欧路/AnkiConnect 生态 | 生词本已有导出，加本机 AnkiConnect(29537) HTTP 直推，收藏即出卡 | 低 |
| 4 | **阅读模式清洗（断行还原）** | CopyTranslator 招牌 | 划词/剪贴板取到论文类文本时合并硬换行、去页眉页脚噪声再翻译；开关放「翻译」页 | 低 |
| 5 | **悬停取词（不打断式）** | 沉浸式翻译 2025-04 划词 | 选中文字后鼠标旁浮出小图标，点击才翻译——替代"必须记住热键"，降低首次使用门槛；复用现有取词链路与小窗 | 低-中 |
| 6 | **引擎额度/失败看板** | 品类通用差评「免费额度耗尽无提示」 | 引擎页每卡显示近 7 天 成功/失败/降级 计数与最近失败原因，替代一次性 toast | 低 |

### P1 中等成本（差异化主战场）

| # | 功能 | 借鉴 | 说明 | 成本 |
|---|---|---|---|---|
| 7 | **TM 复用：相似句回填** | memoQ 预翻译 | 翻译前查历史，编辑距离/包含度 > 阈值时直接回填并标"来自历史"，秒出结果强化「快到无感」；纯本地 SQLite 模糊匹配即可起步 | 中 |
| 8 | **LLM 语境化翻译** | DeepL/ChatGPT 工作流 | AI 引擎把「上下文窗口」喂进 prompt：同一段被反复翻译时携带前文；划词场景携带剪贴板前一条记录作语境 | 中 |
| 9 | **批量 OCR（图片/PDF 文件夹）** | Umi-OCR | 拖入文件夹 → 逐张识别（Paddle 常驻模式天然适配）→ 导出 txt/md/csv；复用现有 OCR 管线 | 中 |
| 10 | **本地 HTTP API** | Umi/Pot 插件生态 | 127.0.0.1 端口（token 鉴权 + DPAPI）暴露 translate/ocr 接口，供脚本、浏览器扩展、AutoHotkey 调用；Pot 归档后开发者社区正在找替代 | 中 |
| 11 | **mdx 离线词典导入** | 欧路生态 | 划词结果卡上方增加"词典释义"层（词头精确匹配 + 音标/释义展示），生词本自动携带词典义 | 中 |
| 12 | **原位覆盖视觉升级** | PixPin 图→图译文 | 现有 InPlace 已覆盖底色替换文字，补：采样原文字色/字号匹配、表格线保留（Paddle 结构识别） | 中 |

### P2 战略押注（先做可行性探针，不排期）

| # | 功能 | 依据 | 备注 |
|---|---|---|---|
| 13 | PDF/EPUB 保留排版双语对照 | 沉浸式翻译最赚钱的功能 | 排版还原工程量大；可先做「PDF 逐段提取→小窗对照」的降级版 |
| 14 | 视频/音频字幕翻译 | BibiGPT 方向 | 需 ASR；与速译"秒级即走"定位偏离，谨慎 |
| 15 | 端侧小模型离线翻译 | 2026 端侧 AI 趋势 | 隐私 + 免密钥 + 断网可用三重卖点；体积与内存是硬约束（200MB 门禁） |
| 16 | 插件式引擎脚本 | Pot 遗珠 | 承接 Pot 外溢用户；先靠 #10 HTTP API 打底 |

### 明确不建议做

- **账号/云同步**：与本地优先定位冲突，且是沉浸式泄露差评的根源。
- **实时同传/会议字幕**：场景完全不同，摊薄"快到无感"。
- **广告/会员弹窗**：品类差评第一名。

## 4. 规避清单（品类差评集中点 → 速译对策）

| 坑 | 速译现状/对策 |
|---|---|
| 收藏/历史数据丢失（有道会员到期清空投诉） | 数据本机 SQLite + 明文可导出；任何功能不得云端化用户数据 |
| 以安全为名收回自定义 API（沉浸式） | AI 端点自定义写进品牌承诺，文档明示永不收回 |
| 国外引擎静默失败 | FR-028 已降级 + 状态行说明；#6 看板进一步显式化 |
| OCR 中英混排串行/标点粘连 | Paddle 双跑择优已部分缓解；#4 清洗规则统一处理 |
| 高分屏错位/取词失效 | FR-025 物理像素定位已解决；#5 悬停取词需同样走 UIPI 探测 |
| 免费额度耗尽无提示 | #6 引擎看板覆盖 |

## 5. 推荐执行顺序

```
下一批（v3.1 候选）：#1 术语表 → #2 隐私模式 → #4 阅读清洗 → #6 引擎看板   （全部低成本，质量+信任双收）
再下一批：#5 悬停取词 → #3 Anki 直推 → #7 TM 回填                          （体验差异化）
探针：#10 HTTP API（Pot 用户承接窗口期存在时效性，建议提前评估）
```

> 注：本清单与 UI v3.0 Fluent 重设计解耦；#5 悬停图标、#6 看板、#2 托盘态需同步进 v3.0 设计稿评审。
